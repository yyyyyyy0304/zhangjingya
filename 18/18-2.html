Canvas · 电商系统总体架构图

张婧雅 · 纯 Canvas 2D 手绘架构图

整张图由 Canvas 2D API 逐帧绘制：客户端 / 接入 / 业务服务 / 数据存储 四层分区， 23 个功能节点、30 余条调用与数据链路。连线上的流动光点表示流量方向， 鼠标悬停节点可查看说明，点击节点会高亮其全部上下游链路。
电商系统 · 四层架构 canvas 2d · 自绘节点与贝塞尔连线

分层设计

客户端层负责多端入口，接入层做 CDN、负载均衡、反向代理与统一鉴权， 业务服务层按领域拆分微服务，数据层按读写特征选择 MySQL / Redis / ES / MQ。

绘制方式

圆角矩形 + 分层色带 + 竖排层名；跨层连线用三次贝塞尔曲线， 同层链路走水平曲线；端点自绘箭头，连线上叠加沿路径运动的高光点。

交互与适配

节点命中检测基于矩形坐标；悬停显示说明气泡，点击锁定高亮， 其余元素淡出；DPR 自适应，窗口变化时重新计算四层布局。

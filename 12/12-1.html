CSS 变量（自定义属性）

张婧雅 · 用 -- 声明一次、用 var() 处处引用的样式管理方式。

一、什么是 CSS 变量

CSS 变量正式名称叫自定义属性：以两个减号 -- 开头来声明，通过 var() 读取。它和 JS 变量一样可以被重新赋值，是目前最常用的"换肤 / 统一设计规范"手段。

:root {
    --zhang-primary: #2d7c7a;
}

h1 {
    color: var(--zhang-primary);
}
写法 作用
--zhang-primary: #2d7c7a; 声明一个自定义属性（必须以 -- 开头）
var(--zhang-primary) 读取变量的值
var(--zhang-primary, #999) 变量不存在时使用回退值 #999
--zhang-primary: var(--zhang-accent); 变量的值也可以引用另一个变量

二、定义位置与作用域

变量和普通属性一样遵循作用域与继承规则：

定义位置 生效范围
:root { } 整个文档（推荐写颜色、字号、间距等全局规范）
普通选择器 .card { } 该元素及其子元素，子元素可重新赋值覆盖
@media 内 媒体查询里改变量，即可整体换一套样式
这个区域里我把 --zhang-primary 改成了紫色、--zhang-accent 改成了金色（只写在本容器上）：
内部的标题 ← 这里是紫色，边框虚线是金色；离开这个容器又恢复成页面默认的青色 / 橘色。

上面效果只靠一条规则 .zhang_scope-box { --zhang-primary: #8e5bbf; } 实现，内部所有用到变量的样式自动跟着变——这就是"一处修改、处处生效"。

三、当前页面用到的变量

本页所有颜色、圆角、间距都来自 :root 中的变量，色板直接用变量上色：

主色--zhang-primary
强调色--zhang-accent
卡片背景--zhang-card
页面背景--zhang-bg

四、实战：一键切换主题

切换按钮只是给 <body> 加上 zhang_dark 类，在这个类里把变量重新赋值，页面所有元素自动换色，不需要逐条改样式：

.zhang_dark {
    --zhang-bg: #14202a;
    --zhang-card: #1d2c38;
    --zhang-text: #e8eef2;
}
当前：浅色主题（--zhang-bg = #f6f2ea）

五、注意事项

问题 说明
变量名区分大小写 --Primary 与 --primary 是两个不同变量
只能当"值"用 不能用变量拼出选择器名或属性名，如 var(--name)-box 不合法
未定义且无回退值 该条声明无效（属性取继承值或初始值），可在控制台看到黄色警告
大小写颜色值 #2D7C7A 和 #2d7c7a 等价，回退值也不用加引号
不能写在 <img> 等替代内容上 变量只作用于文档树中的普通元素样式

兼容性：CSS 变量属于 CSS3 特性，IE11 不支持；现代浏览器（Chrome、Edge、Firefox、Safari 新版本）均已原生支持，无需任何外部库。

2. 实现要点

  • position: fixed; left: 0; right: 0; bottom: 0; width: 100% —— 导航始终贴在视口底部，且占满全屏宽度
  • display: flex + 每项 flex: 1 1 0 —— 4 个导航项等分整行，宽度随屏幕自适应，不写死像素
  • 图标来自 ../font/iconfont.css：<i class="iconfont icon-31shouye">，颜色用 color 继承，选中项换主色
  • 数字徽章 .zhang_badge 与红点 .zhang_dot 用 position: absolute 定位在图标的右上角
  • env(safe-area-inset-bottom) 预留 iPhone 底部安全区（小横条）
  • 正文 padding-bottom 加大，避免最后的内容被固定导航遮住

3. 关键代码

<link rel="stylesheet" href="../font/iconfont.css">

.zhang_nav {
  position: fixed;
  left: 0; right: 0; bottom: 0;
  width: 100%;                 /* 全屏宽度 */
  display: flex;
  padding-bottom: env(safe-area-inset-bottom);
}
.zhang_tab { flex: 1 1 0; }    /* 4 项等分，宽度自适应 */
.zhang_tab-ico { position: relative; }
.zhang_badge  { position: absolute; top: -7px; right: 2px; }
.zhang_dot    { position: absolute; top: -4px; right: -10px; }

  • 首页 icon-31shouye字体图标通过 @font-face 加载，用 class 显示对应字符

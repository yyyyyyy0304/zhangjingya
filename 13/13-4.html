2. 实现要点

  • 把 iconfont 的 4 个 symbol 内联成一份 SVG sprite，<use href="#zhang_icon_shouye"> 复用同一份路径
  • 路径上的 fill="#272536" 改成 fill="currentColor"，配合 .zhang_tab-icon { fill: currentColor }，颜色跟随外层 color，选中项直接换色
  • viewBox="0 0 1024 1024" + 固定 26×26 显示尺寸，矢量缩放任意分辨率都清晰
  • position: fixed; left: 0; right: 0; bottom: 0; width: 100% —— 导航始终贴在视口底部，且占满全屏宽度
  • display: flex + 每项 flex: 1 1 0 —— 4 个导航项等分整行，宽度随屏幕自适应
  • 数字徽章 .zhang_badge 与红点 .zhang_dot 用 position: absolute 定位在图标的右上角
  • env(safe-area-inset-bottom) 预留 iPhone 底部安全区（小横条）

JavaScript 定时器

张婧雅 · setTimeout 与 setInterval

JavaScript 提供两种定时器：setTimeout()（延迟执行一次）和 setInterval()（每隔一段时间重复执行）。 对应的清除方法分别是 clearTimeout() 和 clearInterval()。

① setTimeout — 延迟执行一次

setTimeout 语法 单次定时 
// 语法：setTimeout(回调函数, 延迟毫秒数, 传给回调的参数...)
var timer = setTimeout(function() {
    console.log('3 秒后执行');
}, 3000);

// 在执行前可以取消
clearTimeout(timer);
演示：设置延迟时间，点击开始倒计时

② setInterval — 重复执行

setInterval 语法 循环定时 
// 语法：setInterval(回调函数, 间隔毫秒数)
var timer = setInterval(function() {
    console.log('每隔 1 秒执行一次');
}, 1000);

// 停止循环
clearInterval(timer);

③ 实际应用 — 实时时钟

用 setInterval 实现数字时钟 经典场景 
// 每秒更新一次时间显示
setInterval(function() {
    var now = new Date();
    console.log(now.toLocaleTimeString());
}, 1000);

④ setTimeout vs setInterval 对比

核心区别 一图看懂
对比项 setTimeout setInterval
执行次数 1 次（延迟后执行一次就结束） 多次（每隔间隔重复执行）
清除方法 clearTimeout(id) clearInterval(id)
返回值 定时器 ID（数字） 定时器 ID（数字）
典型场景 延迟弹窗、防抖、动画结束回调 轮播图、倒计时、实时时钟、轮询
会阻塞吗？ 不会（异步，不影响主线程） 不会（异步，不影响主线程）
能递归替代？ 能（在回调里再调 setTimeout 可模拟循环） —
精度问题 延迟可能因事件队列排队而 变长 间隔可能因回调执行耗时而 漂移
递归 setTimeout 是比 setInterval 更安全的方式：在上一次回调完成后再设定下一次， 避免回调执行时间 > 间隔 时导致的重叠堆积。
setTimeout(function fn() { /* do */ setTimeout(fn, 1000); }, 1000);
小结：
① setTimeout(fn, ms) — 延迟 ms 毫秒后执行一次，用 clearTimeout() 取消；
② setInterval(fn, ms) — 每隔 ms 毫秒重复执行，用 clearInterval() 停止；
③ 两者都返回一个 ID（数字），传给清除函数即可取消；
④ 定时器是异步的，不会阻塞后续代码；
⑤ 推荐用递归 setTimeout 替代 setInterval，避免回调堆积。

Promise & async 包饺子

张婧雅 · 异步操作流程演示

用 Promise 和 async/await 模拟包饺子的完整异步流程：
买原料（线上线下同时购买，任一完成即可）→ 取原料 → 同时和面 + 和馅 → 包饺子 → 煮饺子 → 吃饺子。 每个步骤用 setTimeout 模拟耗时，页面实时展示执行进度。

① 流程图

包饺子流程 串行 + 并行
线上买 (6s) 线下买 (4s) → 取原料 (2s) → 和面 (4s) 和馅 (3s) → 包饺子 (5s) → 煮饺子 (4s) → 吃饺子 (2s)
关键点：
① 买原料：线上(6s)、线下(4s) 同时购买，用 Promise.race() 竞速，任一完成即可进入下一步（实际等 4s）；
② 取原料：串行（依赖买原料完成）；
③ 和面、和馅：并行执行，用 Promise.all() 等待两者都完成；
④ 包饺子 → 煮饺子 → 吃饺子：串行，每步依赖前一步。
预计总耗时：min(6, 4) + 2 + max(4, 3) + 5 + 4 + 2 = 21 秒

② 核心代码

Promise + async/await 实现 原生 JavaScript 
// 用 Promise 封装一个异步任务（setTimeout 模拟耗时）
function zhang_task(name, seconds) {
    return new Promise(function(resolve) {
        setTimeout(function() {
            resolve(name);
        }, seconds * 1000);
    });
}

// async 函数编排完整流程
async function zhang_makeDumplings() {
    // ① 买原料：线上线下同时买，任一完成即可（Promise.race 竞速）
    await Promise.race([
        zhang_task('线上买', 6),
        zhang_task('线下买', 4)
    ]);  // 实际等待 min(6, 4) = 4s

    // ② 取原料（串行）
    await zhang_task('取原料', 2);

    // ③ 和面 + 和馅：同时进行，两者都完成（Promise.all）
    await Promise.all([
        zhang_task('和面', 4),
        zhang_task('和馅', 3)
    ]);  // 实际等待 max(4, 3) = 4s

    // ④ 包饺子（串行）
    await zhang_task('包饺子', 5);

    // ⑤ 煮饺子（串行）
    await zhang_task('煮饺子', 4);

    // ⑥ 吃饺子（串行）
    await zhang_task('吃饺子', 2);
}

小结：
① Promise 封装异步操作，resolve() 标记完成；
② async/await 让异步代码像同步一样写，await 等待 Promise 完成；
③ 竞速：Promise.race([p1, p2]) 同时执行，任一完成即可（买原料：线上 vs 线下）；
④ 并行：Promise.all([p1, p2]) 同时执行，等全部完成（和面 + 和馅）；
⑤ 串行：多个 await 顺序执行（取原料 → 包饺子 → 煮饺子 → 吃饺子）；
⑥ setTimeout 模拟每步耗时，页面实时展示进度。

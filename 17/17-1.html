JSON 数据格式

张婧雅 · JavaScript Object Notation

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式。它用键值对和数组来组织数据， 人类读得懂、机器解析得快。前后端通信、配置文件、本地存储几乎都离不开它。

① JSON 长什么样

一段典型的 JSON 键值对 + 数组
{
    "name": "张婧雅",
    "age": 20,
    "isStudent": true,
    "hobbies": ["摄影", "前端", "音乐"],
    "address": {
        "city": "西安",
        "school": "某某大学"
    },
    "graduation": null
}
语法高亮后的树状结构：
JSON 里只有 6 种数据类型：字符串（双引号）、数字、布尔（true/false）、null、对象 { }、数组 [ ]。 键名必须用双引号，不能加注释，不能有尾逗号。

② JSON vs JavaScript 对象

长得像，但规则不同 对比
对比项 JSON JS 对象
键名引号 "name" 必须双引号 name 或 'name' 都行
字符串引号 "你好" 只能双引号 '你好' "你好" 都行
函数 / undefined 不允许 可以 属性值可以是函数
尾逗号 不允许 {a:1,} 允许
注释 不允许 可以 // /* */
本质 字符串（文本格式） 内存中的对象

③ JSON.parse() — 字符串 → 对象

把 JSON 字符串解析成 JS 对象 反序列化
var zhang_str = '{"name":"张婧雅","age":20,"hobbies":["摄影","前端"]}';

var zhang_obj = JSON.parse(zhang_str);
// 现在可以用 .name 取值了
zhang_obj.name;       // "张婧雅"
zhang_obj.hobbies[0]; // "摄影"

④ JSON.stringify() — 对象 → 字符串

把 JS 对象序列化成 JSON 字符串 序列化
var zhang_obj = {
    name: '张婧雅',
    age: 20,
    isStudent: true,
    sayHi: function() {}   // 函数会被自动忽略！
};

JSON.stringify(zhang_obj);
// → '{"name":"张婧雅","age":20,"isStudent":true}'

JSON.stringify(zhang_obj, null, 2);
// 第二个参数 null = 不过滤，第三个 2 = 缩进 2 空格（美化输出）

⑤ 实际场景 — 后端返回的数据

模拟接口返回的 JSON 数据 最常见用法
// 后端 API 返回的通常是 JSON 字符串
var zhang_response = '{"code":200,"msg":"OK","data":{"total":3,"list":[{"id":1,"title":"茶的起源"},{"id":2,"title":"泡茶技艺"},{"id":3,"title":"茶具介绍"}]}}';

// 前端拿到后第一步：parse 成对象
var zhang_res = JSON.parse(zhang_response);

if (zhang_res.code === 200) {
    console.log('共 ' + zhang_res.data.total + ' 篇文章');
    zhang_res.data.list.forEach(function(item) {
        console.log(item.id + ': ' + item.title);
    });
}

⑦ 常见错误 — 这些 JSON 都不合法

排雷指南 踩坑合集
// ❌ 键名没加引号
{ name: "张婧雅" }
// ❌ 用了单引号
{ 'name': '张婧雅' }
// ❌ 尾逗号
{ "name": "张婧雅", }
// ❌ 多了注释
{ "name": "张婧雅" // 姓名 }
// ❌ 值是 undefined / 函数
{ "fn": function() {} }
小结：JSON 就是有严格规则的文本格式。 记住三件事 ——
① 键和字符串值只用双引号；
② JSON.parse() 把字符串变成对象，JSON.stringify() 把对象变成字符串；
③ 不能有函数、注释、尾逗号、单引号。

Fetch 获取接口数据

张婧雅 · fetch + DummyJSON Products API

使用原生 fetch() 请求 https://dummyjson.com/products 接口， 该接口支持跨域访问（CORS），返回 JSON 格式的商品数据。页面加载后自动获取并展示商品列表。

① fetch 基本语法

fetch 请求接口的标准写法 Promise 链式调用
fetch('https://dummyjson.com/products')
  .then(function(res) {
    if (!res.ok) throw new Error('HTTP ' + res.status);
    return res.json();       // 把响应体解析成 JSON
  })
  .then(function(data) {
    console.log(data);       // { total, products: [...] }
  })
  .catch(function(err) {
    console.error('请求失败：', err);
  });

小结：fetch 是浏览器原生的 HTTP 请求 API，返回 Promise。
① fetch(url) 发起请求；
② .then(res => res.json()) 把响应解析成 JS 对象；
③ .catch() 捕获网络错误或 HTTP 异常。
该接口已开启 CORS，前端可直接跨域访问，无需代理。

CSS 长度单位

Web 前端里给尺寸赋值的各种单位：绝对单位、相对字体单位、视口单位、百分比与 fr。

一、绝对单位

与固定物理尺寸绑定，换算关系固定，不随字体、视口变化。屏幕上 1 英寸按 96 像素计算。

单位 含义 换算
px 像素（最常用） 1in = 96px
in 英寸 1in = 2.54cm
cm / mm 厘米 / 毫米 1cm ≈ 37.8px
q 1/4 毫米 4q = 1mm
pt 磅（印刷单位） 1pt = 1/72 in ≈ 1.33px
pc 派卡 1pc = 12pt = 16px

下面六条色条写法不同，实际长度完全一样（都是 96px），拖动窗口也不会变：

width: 96px
width: 1in
width: 2.54cm
width: 25.4mm
width: 72pt
width: 12pc

二、相对字体单位（em、rem、ex、ch）

单位 参照对象
em 当前元素自己的 font-size（逐层嵌套会叠加）
rem 根元素 html 的 font-size（默认 16px，永远不叠加）
ex 当前字体中小写 x 的高度
ch 当前字体中数字 0 的宽度

同一个 width: 10em，父级字号变了结果就变；width: 10rem 在两组里始终一样：

父级 font-size: 14px

10em = 140px（跟随字号） 10rem = 160px（只看根字号）

父级 font-size: 28px

10em = 280px（跟随字号） 10rem = 160px（只看根字号）

em 写在 padding、border、margin 上时，同样按当前元素的 font-size 计算；这就是它适合写"跟文字一起缩放的间距"的原因。

三、相对视口单位（vw、vh、vmin、vmax）

单位 参照对象
vw 视口宽度的 1%（1vw = 视口宽 / 100）
vh 视口高度的 1%
vmin vw 和 vh 中较小的那个
vmax vw 和 vh 中较大的那个
width: 25vw（视口的 1/4）
width: 50vw（视口的一半）
width: 75vw（视口的 3/4）

拖动浏览器窗口宽度，上面三条会跟着伸缩——这就是响应式布局的基础。注意 100vw 包含滚动条宽度，可能比内容区略宽。

四、百分比（%）

相对"父元素"计算：宽、宽相关属性按父元素宽度，高度按父元素高度（父级没有确定高度时无效）。

外层 width: 80%（页面的 80%）
中层 width: 50%（父级的 50% = 页面的 40%）
内层 width: 50%（父级的 50% = 页面的 20%）

margin、padding 写百分比时，参照的也是父元素的宽度，与高度无关。

五、fr（网格轨道份额）

只在 display: grid 的 grid-template-columns/rows 中使用，表示"剩余空间按比例分配"。

1fr
2fr
1fr

三列比例 1 : 2 : 1，中间一列的宽度是两侧的两倍；gap 会先扣掉，再分 fr。

六、常用换算速查

写法 换算结果
1in 96px
1pt ≈ 1.333px
1pc 16px
10em（当前字号 16px 时） 160px
10rem（根字号 16px 时） 160px
50vw / 50vh 视口宽 / 高的一半
数字 0 可以不带单位，如 margin: 0

实际开发中最常用 px 与 rem；做流式、响应式布局用 %、vw、fr；需要"跟字号联动"的间距用 em。

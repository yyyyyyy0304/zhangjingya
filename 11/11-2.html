CSS3 3D 动画

perspective、preserve-3d、rotate3d 与 transition / @keyframes 组合出的立体效果。

一、进入 3D 世界

默认页面是 2D 平面（X 水平、Y 垂直）。perspective 为元素提供"视点距离"，元素沿 Z 轴（垂直屏幕向外）移动时才会出现近大远小的透视效果。

属性 作用
perspective: 800px 观察者到 Z=0 平面的距离，数值越小透视越夸张
perspective-origin 视点位置，默认为元素中心（50% 50%）
transform-style: preserve-3d 让子元素保留在 3D 空间（默认 flat 会被压平）
backface-visibility: hidden 隐藏背面，翻转卡片必备
把鼠标放上来：倾斜并靠近你

五、常用 3D 变换函数

写法 说明
rotateX(45deg) 绕水平轴上下翻转
rotateY(45deg) 绕垂直轴左右翻转
rotateZ(45deg) 绕屏幕法线旋转（等同 2D 的 rotate）
rotate3d(x, y, z, angle) 绕自定义轴旋转，如 rotate3d(1, 1, 0, 45deg)
translateZ(100px) / translate3d(x, y, z) 沿 Z 轴推近拉远，3D 深度的来源
scale3d / matrix3d 3D 缩放与完整矩阵（一般由工具生成）

3D 动画三要素：perspective（空间） + preserve-3d（保留立体） + transition / @keyframes（时间）。悬停上面的演示可暂停，缩放窗口可观察透视变化。

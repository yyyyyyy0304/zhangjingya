JavaScript 对象

张婧雅 · Object 可视化演示

数组用 下标 存一串数据，对象用 属性名 存一组描述。一个对象就像一张身份证：每一条信息都有名字（key），也都有内容（value）。
字符串 String
数字 Number
布尔 Boolean
函数 Function
嵌套对象 Object

① 对象是什么 — 键值对的集合

对象字面量 key : value
var zhang_person = {
    name: '张婧雅',          // 字符串
    age: 20,                // 数字
    isStudent: true,        // 布尔
    hobbies: ['摄影', '前端'],
    sayHi: function() {      // 函数 → 叫「方法」
        return '你好，我是' + this.name;
    }
};
在浏览器里看到的结构：
左边的 name / age / isStudent 叫 属性名（键），冒号右边的叫 属性值； 属性值是函数时，这个属性被称为 方法。
对象 vs 数组 取值方式不同

数组：靠数字下标

[0] 张婧雅 [1] 20 [2] true

换个人写程序就不知道 [1] 是什么了。

对象：靠属性名

name: '张婧雅' age: 20 isStudent: true

每一份数据都有名字，看一眼就懂。

② 创建对象的四种方式

从最常用到最特殊 推荐字面量

① 字面量 { }

var o = { a: 1 };

最常用、最直观，日常开发首选。

② new Object()

var o = new Object();

创建空对象，再逐个添加属性，等价于 { }。

③ 构造函数 + new

new Person('张婧雅')

批量创建同结构对象时用，相当于模板。

④ Object.create()

Object.create(proto)

指定原型创建，进阶用法，了解即可。

构造函数 — 批量造对象 new
function Person(name, age) {
    this.name = name;      // this 指向新建出来的对象
    this.age = age;
}
var zhang_a = new Person('张婧雅', 20);
var zhang_b = new Person('李同学', 21);
// 同一个模板，造出两份独立的数据

③ 访问属性 — 点语法 与 方括号

两种写法，结果一样 动态键用方括号
var zhang_book = { title: '高级网页设计', price: 59 };

zhang_book.title;          // ✅ 点语法：简单直接
zhang_book['title'];      // ✅ 方括号：键名写成字符串

var zhang_key = 'price';
zhang_book[zhang_key];     // ✅ 方括号能放变量（点语法不行）
zhang_book.zhang_key;      // ❌ undefined：会去找名为 zhang_key 的属性
点下面的按钮，看哪一行被点亮：
属性名里有空格、横杠，或者要 用变量当键名、键名是数字时，只能用方括号。

④ 增、删、改 — 对象是活的

直接赋值就能新增或修改 delete 删属性
var zhang_user = { name: '张婧雅', age: 20 };

zhang_user.email = 'zjy@example.com';  // 新增：属性不存在就是加
zhang_user.age = 21;                    // 修改：属性存在就是改
delete zhang_user.age;                // 删除属性（连同值一起消失）

⑤ 方法 与 this — 对象自己的函数

属性值是函数 = 方法 this 指向调用者
var zhang_person = {
    name: '张婧雅',
    age: 20,
    introduce: function() {
        return '我是' + this.name + '，今年' + this.age + '岁';
    },
    growUp: function() {
        this.age++;              // 方法内部改自己的属性
        return this.age;
    }
};

zhang_person.introduce();   // "我是张婧雅，今年20岁"
对象：
this 不看函数写在谁里面，只看 谁在调用它：zhang_person.introduce() 里的 this 就是 zhang_person。

⑥ 遍历对象 — 把每个属性走一遍

for...in 拿到的是键名
var zhang_score = { 语文: 92, 数学: 88, 英语: 95 };

for (var zhang_k in zhang_score) {
    console.log(zhang_k + ': ' + zhang_score[zhang_k]);
}
// ⚠ 注意：for...in 遍历数组拿到的是字符串下标，数组请用 for...of
点击按钮逐行执行（当前行高亮）：
Object.keys / values / entries 把对象拆成数组
var zhang_score = { 语文: 92, 数学: 88, 英语: 95 };

Object.keys(zhang_score);     // ['语文','数学','英语'] — 所有键
Object.values(zhang_score);   // [92, 88, 95] — 所有值
Object.entries(zhang_score);  // [['语文',92], ...] — 键值对数组
Object.keys(zhang_score).length;  // 3 — 数属性的个数

⑦ 嵌套与解构 — 对象里套对象

一层层往里取 ?. 可选链
var zhang_student = {
    name: '张婧雅',
    contact: {
        phone: '138****8888',
        address: { city: '西安', school: '某某大学' }
    }
};

zhang_student.contact.address.city;    // '西安'
zhang_student.contact.qq;              // undefined（没这属性，不报错）
zhang_student.abc.def;                 // ❌ TypeError：undefined 上再取属性
zhang_student.abc?.def;                // ✅ undefined（?. 短路，不报错）

解构赋值 一行拆出变量
var { name, age } = zhang_person;       // name = '张婧雅'，age = 20
var { name: zhang_nick } = zhang_person; // 重命名为 zhang_nick
var { gender = '女' } = zhang_person;   // 默认值：属性不存在时用

⑧ Object 的常用工具方法

合并 / 冻结 / 判断 Object.assign 等
var zhang_base = { name: '张婧雅', age: 20, city: '西安' };
var zhang_patch = { age: 21, email: 'zjy@example.com' };

Object.assign({}, zhang_base, zhang_patch);
// 后面的同名属性覆盖前面 → { name:'张婧雅', age:21, city:'西安', email:'...' }

Object.freeze(zhang_base);   // 冻结：之后改属性无效（严格模式报错）
'age' in zhang_base;          // true — 判断属性是否存在
